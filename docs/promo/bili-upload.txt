简介（可直接粘贴）
------------------------------------------------------------
PCV（PAINCHARNWAV）3.0。

它是一个**只负责装框架的壳**：自己不带任何功能，能力全部来自可装卸的框架包。
界面六页——桌面 / 安装 / 框架 / 市场 / 版权 / 新手引导，软件在前，框架在它后面。

这一版做的事：
· 界面按 TRM UI 的设计系统重写：白色外壳 + 内嵌工作区，浅色 / 深色一键切换，不用重开窗口
· 市场里挑官方做好的包，点一下就下载、校验、装到桌面
· 粘贴就能装：AI 给的构建脚本贴进来，跑完自动装上，不用点第二次
· 自动更新：同时问服务器和 GitHub，有新版本只给提示和链接，不静默下载
· 代码全部重写：加载器、契约、进程运行时、主题、微软登录，已经没有上游源码

技术上的取舍：
· 框架两种形态——.NET 程序集（进程内）和任意语言进程（python / node / exe，自带窗口）
· 进程型框架**不是内核沙箱**：拿不到宿主对象，但文件系统层面还是同一个用户
· 微软登录要自己申请 ClientId，开源版不内置

下载 / 源码：https://github.com/150311-ma/PCV

基于 PCL 的架构思路重写，感谢 龙腾猫跃 的工作。
